A make.fun entry for the competition
[Fortune Cookie for the Liquidated Trader](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c):
a small Python program that writes one fortune cookie line for a crypto
trader who has just been liquidated — oracular in voice, rueful in joke.

Run it with `python3 main.py` and it writes the fortune to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
